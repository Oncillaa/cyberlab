![Python](https://img.shields.io/badge/Python-3.11-blue.svg)

**CyberLab** — это интерактивная веб-платформа для изучения основ кибербезопасности, созданная в стиле TryHackMe. Решай задания, зарабатывай очки, поднимайся в рейтинге!

---

## ✨ Возможности

- 👤 Полноценная система регистрации и авторизации
- 👑 Админ-панель для управления пользователями
- 🌐 Мультиязычность (русский/английский)
- 📚 9 тематических комнат для обучения
- 🎯 45+ заданий разной сложности
- ⭐ Система очков за правильные ответы
- 🏅 Бейджи за достижения
- 📊 Уровни пользователей
- 🏆 Таблица лидеров
- 💡 Подсказки к каждому заданию
- 📊 Отслеживание прогресса
- 🎨 Красивый тёмный интерфейс
- 📱 Адаптивный дизайн (работает на телефоне)
- 💬 Всплывающие уведомления

## 🚀 Быстрый старт

### Требования

- Python 3.8 или выше
- pip

### Установка

\`\`\`bash
# Клонируем репозиторий
git clone https://github.com/Oncillaa/cyberlab.git
cd cyberlab

# Создаём виртуальное окружение (рекомендуется)
python -m venv venv

# Активируем виртуальное окружение
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Устанавливаем зависимости
pip install -r requirements.txt

# Запускаем приложение
python app.py
\`\`\`

Открой браузер и перейди: **http://127.0.0.1:5000**

## 📝 Как пользоваться

1. Зарегистрируйся на платформе
2. Выбери интересующую комнату
3. Решай задания по порядку
4. Вводи ответы в поле под заданием
5. Используй подсказки, если застрял
6. Получай очки за правильные ответы
7. Следи за своим прогрессом в профиле
8. Соревнуйся с другими в таблице лидеров

## 👑 Админ-панель

Для доступа к админ-панели:

1. Зарегистрируйся на платформе
2. Выполни в терминале:
   \`\`\`bash
   python -c "from database import Database; db = Database(); conn = db.get_connection(); cursor = conn.cursor(); cursor.execute('UPDATE users SET is_admin = 1 WHERE username = ?', ('ВАШ_ЛОГИН',)); conn.commit(); conn.close(); print('Готово!')"
   \`\`\`
3. Перейди на \`/admin\`

**Возможности админ-панели:**
- 📊 Просмотр статистики платформы
- 👥 Управление пользователями
- 🗑 Удаление пользователей
- 👑 Назначение/снятие администраторов

## 🔒 Безопасность

- Пароли хешируются с помощью PBKDF2-SHA256
- Защита от SQL-инъекций (параметризованные запросы)
- Проверка авторизации для всех API-запросов
- Декоратор @admin_required для админ-панели
- Защита от XSS (Jinja2 autoescaping)
- CSRF-защита Flask
